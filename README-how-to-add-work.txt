HOW TO ADD A NEW CLIENT WEBSITE TO THE "OUR WORK" PAGE
1. Put the finished client site in a new folder: showcase/<client-name>/ (its own index.html, photos and pages).
2. Copy work-lusega-tales.html to work-<client-name>.html and change the name, description, the folder name in the iframe address, and the "What we built" list.
3. In work.html, copy one project card (an <article class="tc"> block) and update its text, folder and page link.
4. Add the new page to sitemap.xml.
Easiest of all: send the new client site to Claude, and every page, link and menu is updated in one go.

HOW TO ADD A NEW TEMPLATE
Each template is one file named tpl-<name>.html, shown as a card in templates.html. Copy a card block, change the name, price, pages and the file name.
